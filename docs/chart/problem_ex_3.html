課題①の続報（確認フロー運用） / PW-122 エリアマスタ等で発見 / 2026-06-02

運用フロー（課題①の確認フロー）

通常業務 不明点が出たときの一般的な対応
実装に時間がかかるため、不明点を 先んじて連携 しておけば 実装中に回答が返り、止まらず吸収できることが多い（判断で済むものは AI駆動でも同様に対応）。

実運用で見えた課題と方針

出てきた不明点の課題感（3種類）
1
即答が難しい（正解が不明で顧客確認が必要）— 例: エリアマスタの登録項目の確認　実例 →
2
AI駆動の対象外だった（業務ロジック・外部連携が絡む）— 例: ユーザー登録の Cognito 連携
3
資料で網羅的に定義したい（その場の即答ではなく）— 例: Validation・プレースホルダー
解決方針（確認したいこと）
確認
CRUD は基本的にシンプルな実装が多いが、即答が難しい不明点 が出た場合は 業務ロジックの実装タスク等へ寄せる。この切り分け方針でよいか。
