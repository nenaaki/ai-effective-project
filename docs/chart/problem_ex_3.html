課題事例: mock とデータモデルの差分で、実装の正解が定まらず進められないことがある

AIDD 試行で見つかった構造的課題 / PW-122 エリアマスタ試行で発見 / 2026-06-02

現状フロー（mock とデータモデルの差分）

通常業務 仕様と mock に差分があるときの一般的な対応
データモデル（仕様）の確定を待ち、確定箇所から実装する。差分は 関係者に確認 してから該当項目を作る。

課題と論点

課題
mock とデータモデルの差分があると、どちらを正とするかの判断が要り、確定済みの項目でも実装に進められないことがある
背景
mock は 現行システムを踏襲 して項目を表示しているが、データモデル定義は 新システムに合わせて設計 されている。両者の差分により、データモデルにある項目が mock の登録画面に無いことがある。
論点
1
差分があるとき 「どちらを正とするか」 をどう早く判断し、差し戻しの回答待ちを短くするか　実例 →
2
デフォルトの優先（mock か データモデルか）をルール化できるか
3
判断待ちの項目を 保留／仮実装 のどちらで進め、停滞を避けるか
