AI駆動PJタスク管理

このシートの目的
  1. AI駆動開発としての予実管理 — AIによる実装を前提に、各画面・IFの計画工数と実工数を対比し、進捗と完了見込み（マイルストーン）を可視化する。
  2. 作業タスクの割り振り — データモデル／画面項目定義の整備状況からスコア・着手可否を判定し、担当者・実施順を割り当てて並行作業を計画する。

予実管理 (5/25- 週次 / 2名 × 8h/日 × 稼働90% = 14.4h/日 ※5/25は0名・5/26は1名(7.2h)・5/27以降2名)

元データ
  • .work\20260521_○○機能一覧_担当・優先追記.xlsx の 担当列=AI 行を抽出
  • .work\データモデル設計書.xlsx 一覧シート 主な元資料 列を画面名で逆引きしてデータモデル列を生成
  • .work\画面項目定義書.xlsx 画面一覧シート モック 列 + 個別シート存在チェックで画面項目定義列を生成
件数

画面側 96 件 (優先 0=16 / 1=8 / 10=34 / 50=38) ／ IF側 18 件 (全件 優先=1) ／ 合計 114 件

列凡例
  • データモデル: ✅完了 / 🔄作業中 / ・未着手 (空欄=元資料に画面名の言及なし)
  • 状況: 備考と統合表示。進捗ラベル(実装完了=100% / レビュー中=70% / 着手中=50%)はバーンダウン・EVMに加味 / 空欄なら備考の内容(着手可能・実装不可・待機中・バックエンドのみ)を表示
  • 画面項目定義: ✅シートあり(画面項目定義書/管理画面項目定義書 にシート作成済) / 📐モックあり / 🔄作成予定 / ⏸Ph.2以降 / (空欄=画面一覧に該当なし) — 📐 と ✅ は併記しうる

　 (データモデル完成 +10 / データモデル作業中 +5 / モックあり +7 / シートあり +3 (併存可・加算) / 実装不可は0点 → 同点は優先昇順)

工数計算式: 行工数 = (1 + 項目数×0.005) × 処理区分係数 × スコープ係数 × 資産係数 × 3.0 (h)　※1人日=8h
処理区分係数: 閲覧0.7 / 編集1.0 / 新規登録1.3 / DL印刷1.1　・　スコープ係数: 両方ready/データモデル変更1.0 / BEまたはFEのみ0.5 / 実装不可0　・　資産係数: モック+シート両方0.85 / 片方0.95 / なし1.0　・　IF行は1件4h固定

EVM (Earned Value Management)

PV=計画値(線形キャパベース) / EV=出来高(進捗加味) / AC=実コスト(実工数h)　・　EAC = AC + (BAC−EV) / (CPI × SPI)　・　進捗率: 実装完了=100% / レビュー中=70% / 着手中=50%
