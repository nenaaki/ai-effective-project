# イテレーション3 の成果と課題

出典：議事まとめ 2026-09-03 / 09-08 / 09-09 / 09-10 / 09-17、イテレーション3 タスクデータ（2026-09-30 時点）。

## 成果と関連課題

- 計画の 2/3 程度の期間でイテレーション３を完了
  - 進捗が測れていない。夜間RUNは稼働をタスク単位に切り分けられない

    - AI＋人、AIで別々の線を引いてみるのは良いかもしれない
    - AIが「自発的に割り当てられたチケットを開始」できても良いような気がする
      人間の判断が要るタイミングでチケットを人間に戻し、待っている間は別のチケットの作業を進めていく

- エージェントの責務を分割して並列化できるようにしたところ、ボトルネックが見えるようになった
  - PM承認前工程（PMがボトルネックの場合あり）
  - 設計工程（設計レビューは人）★ボトルネック

    - 設計レビューを自動化する方法をイテレーション４の課題として考案してみたい

  - 実装～テスト設計工程（並列）
  - テスト・デバッグ工程（実装よりもAIの待ち時間と消費リソースが大きい）★ボトルネック

    - 複数台並列で解決する可能性が高いと考えている

  - PR・デグレ検査(必要に応じて実装・テストに戻る)

- バグ2％問題：順設計・逆設計の取り入れによる、デバッグ精度の向上と自動化
  - 3度回してダメな場合はAIはその段階で人の助けを求める形にした（イテレーション３で本件は一旦クローズ）

## 小さな改善の積み重ね

- 開発環境とトークンの問題の対策（実施済み）
  - 設計資料を HTML から Markdown + Mermaid へ変更しトークン枯渇（2回発生）を緩和
  - テストフェーズで環境の不安定化（WSL停止）について調査と対策を実施した

- 人間ならすぐに直せるものがなかなか終わらない
  - デグレチェックが厳密すぎる（軽量修正モードの検討中）
