優先度判断のヒント

すぐに画面が必要と思われるもの（カテゴリA）

  • m_shipper（荷主）・m_company（事業会社）・m_business（配送会社）: いずれも配送管理のFK先であり、データ登録がなければ他機能が動かない
  • m_time_slot（時間区分）: 配送時間帯の設定に必要
  • m_product_type（商品種別）: 商品マスタのカテゴリ分類に必要

設計判断が必要なもの（カテゴリD）

  • 顧客マスタ（m_customer）: 設計書では「完了」だが実装ゼロ。スキーマ定義が先決
  • 幹線・水源: mockupページは存在するが完全にmock表示のみ
