AIへの入力
AI に渡す入力の準備の仕方。spec と UX に分けて整理する。
spec
spec 自体に詳細を書き下すのではなく、一次ソースへの参照先を明示するドキュメント。
例:
  • データモデル → docs/データモデル設計書.xlsx の「商品マスタ(product)」シート
  • 業務ルール → docs/業務仕様書.md の §3.2「商品登録フロー」
  • 画面仕様 → docs/画面仕様書.xlsx の「商品マスタ画面」シート
  • UX参考情報 → projects/app-admin-mockup/src/pages/products
UX
画面遷移・レイアウト・コンポーネント挙動を示す。本ケースでは mock（クリッカブルモックアップ） が UX 定義の主体となり、AI はそれを参照して実装する。（Figma やポンチ絵・ワイヤーフレームなどでもよい）
